## 使用

下载 EXE 后双击运行，无需安装 Python。关闭按钮会隐藏到托盘；完全退出请从托盘菜单选择“退出”。

两个版本使用同一个 `%LOCALAPPDATA%\DesktopTodo` 数据目录。切换前先完全退出并备份数据；不能同时运行两个版本。

## 校验

SHA-256 清单：[SHA256SUMS.txt](SHA256SUMS.txt)。Windows 可在 PowerShell 中检查下载文件：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\DesktopTodo-LessPhone.exe'
Get-FileHash -Algorithm SHA256 -LiteralPath '.\DesktopTodo-TaskGroups.exe'
```
